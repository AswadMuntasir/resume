## Portfolio Versions

This repository contains two portfolio versions:

### `index.html` — Gamified Portfolio (Default)
- 7-level game progression system
- Particle effects canvas
- Custom cursor with hover states
- Sound effects (Web Audio API)
- XP bar, minimap navigation, level-up overlays
- Card flip interactions, timeline, skill bars
- Keyboard, scroll, and touch navigation
- Fully responsive (mobile to 4K/TV)

### `index2.html` — Classic Portfolio
- Traditional single-page layout
- Glassmorphism design
- Typing animation
- Smooth scroll navigation
- Contact form section
